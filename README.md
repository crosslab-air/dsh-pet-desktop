# DSH蓝色大肥鱼桌宠 · 独立桌面版（dsh-pet-desktop）

![点击回应 · 开心跃动](assets/demo/dianji-huiying-kaixin-yuedong.gif)

把 **dsh-pet** 这个 DSH 插件剥离成**独立桌面桌宠**：不装 DSH、不要浏览器，双击图标就有一只 Q 版蓝毛小女仆常驻桌面。沿用上游 **106 段动画**与余额峰谷气泡，重做成"像软件一样"的形态 —— **单进程、零控制台窗口、托盘常驻、带设置界面、点击有音效**。

> **来源**：本仓库由 GitHub 仓库 [PC2005-cloud/dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 的 **DSH 插件版**改造而来——在原插件的基础上新增了脱离 DSH 的**桌面版**。本项目沿用 **MIT License**，版权归原作者所有（见 [LICENSE](LICENSE)）：
>
> ```
> Copyright (c) 2026 PC2005-cloud
> Copyright (c) 2026 crosslab-air
> ```

> 桌面版不支持「对话」与「工作状态联动」（这两项依赖 DSH 宿主：前者要宿主 LLM，后者要 DSH 会话事件，桌面环境没有数据源）；周期自动「碎碎念」也已关闭，但右键手动触发仍可用（走本地句库，无需联网、无需 Key）。

## 特性

- 🖥️ **独立桌面应用**：Electron 透明置顶窗，**不依赖 DSH / 浏览器**；开机即用，双击图标就开
- 🪟 **真正的"软件形态"**：本地服务跑在 Electron 主进程内 —— **一个进程、零控制台窗口**；关掉设置窗口不影响桌宠，不会像脚本方案那样"关掉黑框就整只死掉"
- 🎞️ **106 段原版动画**：待机呼吸 / 点击回应 / 拖拽悬空 / 螃蟹走路 / 吃播 / 时节 …… 全部沿用上游素材，一个不少
- 💰 **余额气泡**：点击桌宠（或右键「查看余额」）即拉取 DeepSeek 官方余额，按**峰谷定价**着色（**峰红谷绿**），气泡 10 秒自动收起；余额档位还带 6 档专属动画（钱袋满溢 → 分文不剩）
- 🐤 **点击音效**（本版新增）：按下 / 松开各一声，两套风格（小黄鸭 / 叮咚），可开关、可调音量、可试听，**改动实时生效不用重启**
- ⚙️ **完整设置窗口**：余额概览、API Key、外观缩放（0.6–1.6×）、点击音效、开机自启、桌面快捷方式、文件位置、运行日志、重启 / 退出
- 🧭 **托盘常驻**：显示 / 隐藏桌宠、立即刷新余额、一键创建桌面快捷方式、开机自启动、打开数据目录、查看日志
- 🔐 **数据全在本目录内**：`data/`（日志、配置、图标）与 `userdata/`（Chromium profile）都跟着仓库走 —— **不往 C 盘丢东西**
- 🔒 **Key 只存本地**：写进 `standalone/credential.json`，仓库里给的是空模板 `credential.example.json`
- 🧩 **上游零改动**：`dsh-pet/` 目录一个字没改，所有增强都在 `standalone/` 这层"包一层"实现（详见 [PROVENANCE.md](PROVENANCE.md)）

## 快速开始

### 环境要求

| 项 | 要求 |
|---|---|
| 系统 | Windows 10 / 11（x64） |
| 网络 | **仅首次**需要（自动下载 Electron 运行时，约 300MB） |
| Node.js | **不需要**（Electron 自带；`设置密钥.cmd` 会把它当 Node 用） |
| 管理员权限 | 不需要 |

> **这不是命令行程序。** `启动桌宠.cmd` 只在**第一次**用到 —— 它的角色是"安装器"：下载运行时、然后在**桌面自动创建图标**。从第二次起，你只需要**双击桌面上那个图标**，和任何普通桌面软件一样，没有任何黑框。

### 第一步 · 安装（只做一次）

**① 下载仓库**

```bash
git clone <你的仓库地址> dsh-pet-desktop
```

或直接下载 ZIP 解压。**放在你想长期保留的位置**（比如 `D:\dsh-pet-desktop`）—— 装好之后就别再挪，挪了需要重建一次快捷方式。

**② 双击 `启动桌宠.cmd`**

这一步只做一次，它相当于"安装"：

| 发生什么 | 说明 |
|---|---|
| 下载 Electron 运行时 | 约 300MB，走 npmmirror 镜像，通常 1–5 分钟，窗口里会打印下载进度 |
| 桌宠出现在桌面右上角 | 那个黑框**由它自己退出** —— 它不承载桌宠进程，关掉也不影响桌宠 |
| **桌面自动出现「DSH蓝色大肥鱼桌宠」图标** | 程序自动创建的（见 `standalone/app/main.cjs` 的 `createShortcut()`），**以后就靠它启动** |

**③ 填 API Key**（不填也能跑，只是没有余额气泡）

在桌宠身上**右键 →「设置…」→ API Key** → 粘贴 `sk-` 开头的 Key →「保存并验证」。

> Key 获取地址：<https://platform.deepseek.com/api_keys>

### 第二步 · 日常使用（以后每次）

**只做一件事：双击桌面上的「DSH蓝色大肥鱼桌宠」图标。**

- **零控制台窗口** —— 快捷方式直接调 `electron.exe` 加载 `standalone/app`，不经过 cmd
- 桌宠同时常驻**系统托盘**（右下角小鲸鱼图标）：左键双击开设置，右键是完整菜单
- 想让开机就自动出现 → 托盘菜单 →「开机自动启动」打勾
- 想退出 → 在桌宠身上**右键 →「退出桌宠程序」**（或托盘菜单 →「退出 …」）

> **快捷方式丢了 / 把文件夹挪了位置？** 再双击一次 `启动桌宠.cmd` 就会自动重建（它检测到图标不存在才建，不会打扰你已经有的那个）；也可以在桌宠跑起来后，从托盘菜单点「创建桌面快捷方式」。

<details>
<summary>（可选）不想用 cmd —— 命令行方式填 Key</summary>

双击 `设置密钥.cmd`：

```
请粘贴你的 DeepSeek API Key（sk-…）：
```

正常推荐用设置窗口填，这条只是备选路径。

## 使用说明

### 右键菜单（在桌宠身上点右键）

| 菜单项 | 说明 |
|---|---|
| **打开 DeepSeek 用量页** | 用系统默认浏览器打开 <https://platform.deepseek.com/usage>（谁点开就看谁自己账号的用量） |
| **查看余额** | 立即刷新并弹出余额气泡 |
| **碎碎念** | 手动让桌宠说一句（**本地句库**，配一张随机表情包，不联网、不要 Key） |
| **对话** | ⚠️ 本版不可用（需要宿主 LLM） |
| **回到初始位置** | 停漫游、清位置记忆，回配置里的角落 |
| **重载配置** | ⚠️ 本版是空实现（上游靠宿主重启 Helper）。改完 `config.jsonc` 请用托盘 →「重启桌宠」 |
| **动作** | 级联子菜单：按分类点播任意一段动画 |
| **设置…** | 打开设置窗口（本版新增） |
| **退出桌宠程序** | 彻底退出（本版新增） |

### 托盘菜单（右键系统托盘图标）

`显示/隐藏桌宠` · `设置…` · `立即刷新余额` · `创建桌面快捷方式` · `开机自动启动` · `打开数据目录` · `查看日志` · `退出`

> 托盘图标悬停时会显示程序名；双击托盘图标 = 打开设置窗口。

### 设置窗口

| 卡片 | 内容 |
|---|---|
| **DeepSeek 余额** | 当前金额、峰谷时段标签、距离切换时段倒计时、立即刷新 |
| **API Key** | 状态、输入框（密码态 + 显示）、保存并验证、清空 |
| **外观** | 缩放 0.6–1.6×（保存后重启生效） |
| **点击音效** | 开关 / 风格（小黄鸭・叮咚）/ 音量 / **试听**，改动实时生效 |
| **启动方式** | 开机自启、桌面快捷方式路径、创建 / 修复快捷方式 |
| **文件位置** | 程序目录 / 数据目录 / 配置文件（可一键打开） |
| **运行日志** | 直接看 `data/app.log` 尾部 |
| **程序** | 重启桌宠、退出桌宠程序 |

### 交互一览

- **左键点击** → 随机一段「点击回应」动画 + 立刻弹余额气泡 + 播放音效
- **拖拽** → 抓起来悬空反馈，松手有抛掷物理（可撞墙、可停在地上）
- **漫游** → 空闲时自己散步、做小动作、吃播、过节（全部随机）
- **右键** → 见上表

## 常见问题

- **双击 `启动桌宠.cmd` 只闪一下就没了** → 看 `data/app.log` 尾部；首次大概率是 Electron 没下完。
- **余额显示「缺少余额查询凭证」** → 还没填 Key。右键 →「设置…」→ API Key。
- **窗口一片白 / 桌宠不出来** → 多半是本地服务端口 `8231` 被别的程序占用。日志里会写清楚，改用随机端口后重启一次即可。
- **没有声音** → 设置窗口 →「点击音效」看开关；音量拉到 0 也会静音。
- **怎么退出** → 右键桌宠 →「退出桌宠程序」，或托盘图标右键 →「退出」。注意：**关掉设置窗口只是关了设置**，桌宠还在跑，托盘图标也还在。
- **怎么卸载** → 先退出桌宠，然后删掉整个文件夹 + 手动删掉桌面那个快捷方式即可（托盘菜单只能**创建**快捷方式，删除要自己动手）。
- **桌面图标不见了 / 换了文件夹位置** → 双击一次 `启动桌宠.cmd` 会自动重建；或桌宠跑起来后，托盘图标右键 →「创建桌面快捷方式」。
- **它到底叫什么** → 桌面图标名、托盘悬停提示、托盘退出项、设置窗口标题栏**统一显示「DSH蓝色大肥鱼桌宠」**，没有第二套称呼。想换名字就改 `standalone/app/main.cjs` 顶部的 `APP_TITLE` 与 `SHORTCUT_NAME`。
- **杀软报毒** → Electron 应用未签名时的常见误报。
- **想多开几只** → 编辑 `standalone/config.jsonc` 的 `pets` 数组（`id` 必须唯一），保存后到**设置窗口 →「程序」卡片 → 重启桌宠**（托盘菜单里没有重启项）。
- **想自定义台词 / 动画池 / 物理手感** → 同上，都在 `standalone/config.jsonc` 里。
- **想把「打开 DeepSeek 用量页」换成别的网址** → 改 `standalone/patch-shell.js` 顶部的 `OPEN_SITE_URL`，重启生效。
- **想换音效** → `standalone/sound/*.mp3` 直接替换同名文件即可；想自己合成就用 `scripts/make-sounds.py`。

## 开发与维护

- **上游零改动**：`dsh-pet/` 是上游快照。要加/改行为，一律在 `standalone/` 里做（包装层注入、运行期补丁、本地服务三个手段），详见 [CONTRIBUTING.md](CONTRIBUTING.md)。
- **改了补丁必须重启桌宠**：补丁是启动时注入页面的，热改无效。
- **调试用远程调试端口**：页面里的 `console.log` 不一定进 `data/app.log`，直读页面运行时状态更可靠。
- **深入文档**：时序约束（为什么先 `require` 上游再异步起服务）、宿主契约复刻清单、三个补丁各自接管了什么 —— 见 [`docs/技术说明.md`](docs/技术说明.md)。
- **音效可复现**：`scripts/make-sounds.py` 用纯 Python 标准库生成 WAV，再用 ffmpeg 转 MP3，仓库里这 4 枚文件就是这么来的。
